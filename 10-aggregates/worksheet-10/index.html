    Φύλλο εργασίας — Μάθημα 10: Συγκεντρωτικά αποτελέσματα¶

    Πώς δουλεύουμε

    Η θεωρία είναι στη σελίδα Μάθημα 10. Εδώ είναι οι ασκήσεις. Στις ασκήσεις πρόβλεψης γράψε πρώτα την απάντησή σου και μετά τρέξε την εντολή ή το πρόγραμμα. Μια λάθος πρόβλεψη είναι χρήσιμη: δείχνει τι δεν έχει ακόμη γίνει σαφές. Σήμερα πρόβλεψε κάθε φορά πόσες γραμμές θα έχει το αποτέλεσμα (μία για όλον τον πίνακα, ή μία για κάθε ομάδα) και τι αριθμό θα δείξει.

    Κύκλος Εργασία Αποτέλεσμα
    1 COUNT, SUM, AVG, MIN, MAX, GROUP BY, HAVING Συγκεντρωτικά ερωτήματα στον games
    2 fetchone, fetchall, None, «μπάρες» Αναφορά βιβλιοθήκης στην Python

    Οι δύο κύκλοι είναι οι δύο διδακτικές ώρες του μαθήματος.

    Πριν αρχίσεις, τρέξε το 01-start-state.sql (καρτέλα Import). Για τις προβλέψεις σου θα χρειαστείς τα δεδομένα του πίνακα games (30 γραμμές). Η στήλη description δεν φαίνεται εδώ: είναι NULL παντού, εκτός από το id 9:

    Κύκλος 1 — Συγκεντρωτικά αποτελέσματα στη SQL (45′)¶

    Θεωρία (10′)¶

    Παρακολούθησε την επίδειξη και διάβασε τις ενότητες 1.1–1.5 του μαθήματος.

    Α. Πρόβλεψη (4′)¶

    Με βάση τον πίνακα παραπάνω, πρόβλεψε το αποτέλεσμα κάθε ερωτήματος. Μην τα τρέξεις ακόμη.

    # Ερώτημα Πρόβλεψη
    1 SELECT COUNT(*) FROM games WHERE genre = 'Αθλητικό';
    2 SELECT SUM(price) FROM games WHERE genre = 'Arcade';
    3 SELECT MAX(release_year) FROM games;
    4 SELECT MIN(price) FROM games WHERE genre = 'Παζλ';
    5 SELECT AVG(price) FROM games WHERE genre = 'Στρατηγικής';
    6 SELECT COUNT(description) FROM games;
    7 SELECT COUNT(*), AVG(price) FROM games WHERE genre = 'Δεν υπάρχει';

    Β. Βρες το σφάλμα (4′)¶

    Πρόβλεψε τι θα γίνει με καθένα από τα παρακάτω. Μετά τρέξε τα.

    # Ερώτημα Τι θα γίνει (πρόβλεψη) Διόρθωση
    1 SELECT title, MAX(price) FROM games;
    2 SELECT genre, COUNT(*) FROM games WHERE COUNT(*) >= 3 GROUP BY genre;
    3 SELECT genre, title, COUNT(*) FROM games GROUP BY genre;
    4 SELECT genre, COUNT(*) FROM games HAVING genre = 'Παζλ' GROUP BY genre;

    Ποια από τις τέσσερις δεν δίνει μήνυμα σφάλματος, αλλά δίνει λάθος αποτέλεσμα; Γιατί είναι η πιο επικίνδυνη; ______________________________________________

    2. τον μήνα με τις περισσότερες προσθήκες παιχνιδιών: μήνας και πλήθος (μία γραμμή)·

    Α. Πρόβλεψη (4′)¶

    Δίνεται το παρακάτω κομμάτι προγράμματος (μην το τρέξεις). Η cursor είναι ήδη φτιαγμένη. Τι θα τυπώσει, με τη σειρά;

    cursor.execute("SELECT COUNT(*), AVG(price) FROM games WHERE genre = 'Arcade'")
count, average = cursor.fetchone()
print(count)
print(average)
print(f"{average:.2f}")
print("█" * count)

    Αυτοέλεγχος¶

    • □ Μπορώ να γράψω ερωτήματα με COUNT, SUM, AVG, MIN, MAX και ξέρω τι δίνουν όταν δεν υπάρχουν γραμμές.
    • □ Ξέρω τη διαφορά του COUNT(*) από το COUNT(στήλη) και το COUNT(DISTINCT στήλη).
    • □ Μπορώ να γράψω GROUP BY και ξέρω ποιες στήλες επιτρέπονται στο SELECT.
    • □ Ξέρω τη διαφορά του WHERE από το HAVING και τη σειρά των φράσεων μιας SELECT.
    • □ Μπορώ να πάρω στην Python ένα συγκεντρωτικό αποτέλεσμα και να χειριστώ το Decimal και το None.
    • □ Μπορώ να γράψω αναφορά με βρόχο και «μπάρες».
