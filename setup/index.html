    Εγκατάσταση και ρύθμιση¶

    Σε αυτή τη σελίδα ετοιμάζεις τον υπολογιστή σου για όλα τα μαθήματα: XAMPP (η βάση δεδομένων και το phpMyAdmin) και, από το Μάθημα 3, Python, VS Code και ο οδηγός σύνδεσης της Python με τη MySQL. Στους υπολογιστές του εργαστηρίου συνήθως είναι ήδη εγκατεστημένα· τότε πήγαινε κατευθείαν στη λίστα ελέγχου στο τέλος της σελίδας. Οι οδηγίες γράφτηκαν για Windows.

    Για το Μάθημα 1 χρειάζεσαι μόνο το XAMPP (ενότητα 1). Τα υπόλοιπα χρειάζονται από το Μάθημα 3.

    1. XAMPP¶

    Το XAMPP είναι ένα πακέτο που περιέχει τον εξυπηρετητή βάσεων (MySQL, στην πραγματικότητα MariaDB), τον Apache και το phpMyAdmin. Το Μάθημα 1 εξηγεί τι κάνει το καθένα.

    Έλεγξε πρώτα αν υπάρχει. Έναρξη, γράψε xampp. Αν βρεις το XAMPP Control Panel, το XAMPP είναι εγκατεστημένο· πήγαινε στη «Δοκιμή του XAMPP» παρακάτω.

    Εγκατάσταση

    1. Άνοιξε τη σελίδα https://www.apachefriends.org/download.html και κατέβασε το XAMPP για Windows. Το υλικό δοκιμάστηκε με την έκδοση 8.5 (MariaDB 10.11, phpMyAdmin 5.2). Μια νεότερη έκδοση της ίδιας σειράς 8.x έχει τα ίδια βήματα.
    2. Τρέξε το πρόγραμμα εγκατάστασης. Αν τα Windows ή το antivirus ρωτήσουν, αποδέξου να συνεχίσει.
    3. Αν δεις προειδοποίηση για τον έλεγχο λογαριασμού χρήστη (UAC), πάτα OK· δεν θα εγκαταστήσεις στον φάκελο Program Files.
    4. Στις συνιστώσες (Select Components) χρειάζονται μόνο Apache, MySQL, PHP και phpMyAdmin. Μπορείς να αφήσεις και τις προεπιλογές· οι υπόλοιπες δεν θα χρησιμοποιηθούν.
    5. Στον φάκελο εγκατάστασης άφησε το C:\xampp.
    6. Πάτα Next μέχρι να τελειώσει. Όταν ρωτήσει αν θέλεις να ανοίξει το Control Panel, απάντησε ναι.

    Μην εγκαταστήσεις στο Program Files

    Ο φάκελος C:\Program Files προστατεύεται από τα Windows και το XAMPP δεν μπορεί να γράψει τα δεδομένα του εκεί. Κράτα το C:\xampp.

    Δοκιμή του XAMPP

    1. Άνοιξε το XAMPP Control Panel.
    2. Πάτα Start στον Apache και στη MySQL. Την πρώτη φορά τα Windows ρωτούν αν θα επιτρέψουν την πρόσβαση στο δίκτυο. Τσέκαρε μόνο το Private networks (ιδιωτικά δίκτυα) και πάτα Allow access.
    3. Τα ονόματα Apache και MySQL πρέπει να γίνουν πράσινα. Θα δεις δίπλα τις θύρες (80, 443 και 3306).
    4. Στη γραμμή της MySQL πάτα Admin, ή άνοιξε στον φυλλομετρητή τη διεύθυνση:
    http://localhost/phpmyadmin

    Αν ανοίξει το phpMyAdmin με τη λίστα των βάσεων, το XAMPP δουλεύει.

    Τι βλέπεις Τι κάνεις
    Ο Apache δεν ξεκινά και μιλά για τη θύρα 80 Άλλο πρόγραμμα έχει πιάσει τη θύρα. Πάτα Netstat στο Control Panel για να δεις ποιο, ή ρώτα τον εκπαιδευτικό
    Η MySQL ξεκινά και σταματά αμέσως Πάτα Logs δίπλα στη MySQL και διάβασε τις τελευταίες γραμμές. Συνήθως η θύρα 3306 είναι πιασμένη. Ρώτα τον εκπαιδευτικό
    Ο φυλλομετρητής δεν ανοίγει το localhost/phpmyadmin Ο Apache δεν τρέχει. Πάτα Start
    Το phpMyAdmin γράφει σφάλμα σύνδεσης Η MySQL δεν τρέχει. Πάτα Start

    Όταν τελειώνεις, πάτα Stop στον Apache και στη MySQL πριν κλείσεις τον υπολογιστή.

    Το XAMPP είναι για τον δικό σου υπολογιστή

    Οι προεπιλεγμένες ρυθμίσεις (ο χρήστης root χωρίς κωδικό) είναι βολικές για μάθηση, αλλά δεν είναι ασφαλείς για υπολογιστή που βλέπουν άλλοι από το δίκτυο. Στο Μάθημα 17 θα μάθεις πώς ασφαλίζεται μια βάση.

    2. Python¶

    Από το Μάθημα 3 χρησιμοποιείς Python. Έλεγξε πρώτα αν υπάρχει. Άνοιξε τερματικό (Έναρξη, γράψε terminal ή PowerShell) και γράψε:

    python --version

    Αν απαντήσει Python 3. και έναν αριθμό, π.χ. Python 3.13.5, η Python υπάρχει. Το υλικό δοκιμάστηκε με την Python 3.13: χρησιμοποίησε αυτήν ή μια νεότερη. Αν η εντολή δεν αναγνωρίζεται, ή ανοίγει το Microsoft Store, ακολούθησε τα παρακάτω βήματα.

    Εγκατάσταση

    1. Άνοιξε τη σελίδα https://www.python.org/downloads/windows/ και κατέβασε την Python 3.13 (ή νεότερη) για Windows (64-bit).
    2. Τρέξε το πρόγραμμα εγκατάστασης. Στην πρώτη οθόνη τσέκαρε το κουτάκι Add python.exe to PATH, που βρίσκεται στο κάτω μέρος. Αν το ξεχάσεις, η εντολή python δεν θα αναγνωρίζεται.
    3. Πάτα Install Now, περίμενε να τελειώσει και πάτα Close.
    4. Άνοιξε νέο τερματικό και γράψε ξανά python --version.

    Νέο τερματικό μετά την εγκατάσταση

    Η ρύθμιση PATH διαβάζεται μόνο από τερματικά που ανοίγουν μετά την εγκατάσταση. Αν η εντολή δεν αναγνωρίζεται αμέσως, κλείσε όλα τα παράθυρα του τερματικού (και το VS Code) και άνοιξέ τα ξανά.

    Τι βλέπεις Τι κάνεις
    Το τερματικό λέει ότι η python δεν αναγνωρίζεται Δοκίμασε py --version. Αν δουλεύει, γράφε py αντί για python σε όλα τα μαθήματα. Αλλιώς κατάργησε την Python (Ρυθμίσεις, Εφαρμογές) και ξανακάνε την εγκατάσταση με το κουτάκι Add python.exe to PATH τσεκαρισμένο
    Ανοίγει το Microsoft Store Τα Windows έχουν συντομεύσεις που στέλνουν τις εντολές python και python3 στο Store. Στις Ρυθμίσεις γράψε στην αναζήτηση app execution aliases και απενεργοποίησε τα python.exe και python3.exe
    Η pip δεν αναγνωρίζεται Γράψε python -m pip αντί για pip, όπως στις οδηγίες παρακάτω

    3. VS Code¶

    1. Κατέβασε το VS Code από το https://code.visualstudio.com/ και εγκατέστησέ το. Οι προεπιλογές αρκούν.
    2. Άνοιξε το VS Code. Στο αριστερό μενού πάτα Extensions (ή Ctrl + Shift + X), γράψε Python και εγκατέστησε την επέκταση Python με εκδότη Microsoft.
    3. Άνοιξε τον φάκελο του μαθήματος: File → Open Folder.
    4. Άνοιξε τερματικό: Terminal → New Terminal. Η γραμμή του τερματικού πρέπει να δείχνει τον φάκελο του μαθήματος.

    Στα μαθήματα τρέχουμε τα προγράμματα από το τερματικό, με python όνομα-αρχείου.py. Το κουμπί ▷ (Run Python File) πάνω δεξιά στον επεξεργαστή κάνει το ίδιο.

    4. Ο οδηγός σύνδεσης Python–MySQL (από το Μάθημα 3)¶

    Η Python δεν ξέρει από μόνη της να μιλά με τη MySQL. Χρειάζεται ένα επιπλέον πακέτο, τον οδηγό σύνδεσης (connector). Όταν φτάσεις στο Μάθημα 3, γράψε στο τερματικό:

    python -m pip install mysql-connector-python

    Το πακέτο λέγεται mysql-connector-python, ενώ στον κώδικα εισάγεται ως mysql.connector.

    Δοκιμή. Ξεκίνα τη MySQL από το XAMPP, φτιάξε ένα αρχείο connect-test.py με αυτό το περιεχόμενο και τρέξ' το:

    import mysql.connector

connection = mysql.connector.connect(host="localhost", user="root", password="")
print("Συνδέθηκες:", connection.is_connected())
connection.close()

    Η έξοδος πρέπει να είναι:

    Συνδέθηκες: True
    Τι βλέπεις Τι σημαίνει
    ModuleNotFoundError: No module named 'mysql' Ο οδηγός δεν έχει εγκατασταθεί στην Python που τρέχεις. Ξανακάνε το pip install
    Can't connect to MySQL server on 'localhost:3306' Η MySQL δεν τρέχει. Ξεκίνα την από το XAMPP Control Panel
    Access denied for user 'root' Ο root έχει κωδικό. Ρώτα τον εκπαιδευτικό

    Λίστα ελέγχου¶

    • □ Το XAMPP Control Panel ανοίγει και ξεκινούν ο Apache και η MySQL (πράσινα ονόματα).
    • □ Το http://localhost/phpmyadmin ανοίγει και δείχνει τη λίστα των βάσεων.
    • □ (Για το Μάθημα 3) Η python --version δείχνει Python 3.13 ή νεότερη.
    • □ (Για το Μάθημα 3) Το VS Code ανοίγει φάκελο, ανοίγει τερματικό και βλέπει την Python.
    • □ (Για το Μάθημα 3) Το connect-test.py γράφει Συνδέθηκες: True.

    macOS και Linux

    Οι οδηγίες γράφτηκαν για Windows. Σε macOS και Linux το XAMPP έχει διαφορετικό πρόγραμμα ελέγχου και η εντολή της Python είναι συνήθως python3. Αν δουλεύεις εκεί και κάτι δεν ταιριάζει, ρώτα τον εκπαιδευτικό.
