    Φύλλο εργασίας — Μάθημα 1: Η πρώτη μου βάση δεδομένων¶

    Πώς δουλεύουμε

    Η θεωρία είναι στη σελίδα Μάθημα 1. Εδώ είναι οι ασκήσεις. Στις ασκήσεις πρόβλεψης γράψε πρώτα την απάντησή σου και μετά δοκίμασε στο phpMyAdmin. Μια λάθος πρόβλεψη είναι χρήσιμη: δείχνει τι δεν έχει ακόμη γίνει σαφές.

    Κύκλος Εργασία Αποτέλεσμα
    1 Βάση δεδομένων, πελάτης–εξυπηρετητής, XAMPP, phpMyAdmin Εξυπηρετητής που τρέχει και phpMyAdmin ανοιχτό
    2 Βάση, πίνακας, τύποι, εγγραφές, πρώτη SELECT Βάση game_library με δέκα παιχνίδια

    Οι δύο κύκλοι είναι οι δύο διδακτικές ώρες του μαθήματος.

    Κύκλος 1 — Τι είναι μια βάση δεδομένων (45′)¶

    Θεωρία (15′)¶

    Παρακολούθησε την επίδειξη και διάβασε τις ενότητες 1.1–1.5 του μαθήματος.

    Α. Αντιστοίχιση όρων (4′)¶

    Γράψε δίπλα σε κάθε όρο το γράμμα της σωστής περιγραφής.

    Όρος Γράμμα
    βάση δεδομένων
    ΣΔΒΔ
    πίνακας
    εγγραφή
    πεδίο
    SQL
    • α) Μία γραμμή ενός πίνακα: τα στοιχεία ενός παιχνιδιού.
    • β) Η γλώσσα με την οποία ζητάμε πράγματα από το ΣΔΒΔ.
    • γ) Μία στήλη ενός πίνακα, π.χ. η τιμή.
    • δ) Οργανωμένη συλλογή δεδομένων που αποθηκεύεται μόνιμα.
    • ε) Το πρόγραμμα που αποθηκεύει, βρίσκει και προστατεύει τα δεδομένα (π.χ. η MySQL).
    • στ) Το σημείο της βάσης που κρατά εγγραφές του ίδιου είδους.

    Β. Διάβασε τον πίνακα (4′)¶

    Ο πίνακας players κρατά τους παίκτες ενός παιχνιδιού:

    id nickname level score
    1 Maria 7 1250
    2 Kostas 3 480
    3 Maria 5 910
    4 Elena 7 1730
    1. Πόσες εγγραφές έχει ο πίνακας; ______ Πόσα πεδία; ______
    2. Ποια είναι η τιμή του πεδίου level στην εγγραφή με id = 3; ______
    3. Ποιος παίκτης έχει το μεγαλύτερο score; ______________
    4. Δύο παίκτες λέγονται Maria. Ποιο πεδίο ξεχωρίζει με βεβαιότητα την πρώτη από τη δεύτερη; ______ Γιατί δεν κάνει το nickname; ______________________________________________

    Γ. Σωστό ή λάθος; (3′)¶

    Κύκλωσε Σ ή Λ και γράψε σύντομα γιατί.

    Πρόταση Γιατί;
    1 Όταν κλείσει ένα πρόγραμμα Python, οι τιμές μιας λίστας μένουν στον υπολογιστή. Σ / Λ
    2 Ο Apache και η MySQL είναι το ίδιο πρόγραμμα. Σ / Λ
    3 Για να συνδεθεί ένα πρόγραμμα Python με τη βάση, πρέπει να τρέχει η MySQL. Σ / Λ
    4 Το phpMyAdmin είναι η βάση δεδομένων. Σ / Λ
    5 Μια βάση δεδομένων μπορεί να έχει πολλούς πίνακες. Σ / Λ

    Δ. Στάδιο 1 — Ξεκίνα τον εξυπηρετητή (10′)¶

    1. Άνοιξε το XAMPP Control Panel. Ξεκίνα τον Apache και τη MySQL.
    2. Γράψε τις θύρες που εμφανίζονται όταν τρέχουν: Apache: ______________ MySQL: ______________
    3. Άνοιξε το phpMyAdmin (κουμπί Admin της MySQL) και βάλε το στα αγγλικά.
    4. Στην αρχική σελίδα βρες και γράψε:
    5. Server type: ______________ Server version: ______________
    6. Άνοιξε την καρτέλα Databases. Γράψε τα ονόματα των βάσεων που βλέπεις: ______________________________________________ Πόσες από αυτές έφτιαξες εσύ; ______

    Ε. Τι δουλεύει; (5′)¶

    Σε κάθε γραμμή έχεις ξεκινήσει μόνο ό,τι δείχνει η πρώτη στήλη. Πρόβλεψε τι συμβαίνει, και μετά δοκίμασέ το (σταμάτα και ξεκίνα τα στοιχεία στο Control Panel).

    Τρέχει μόνο… Ανοίγει το localhost/phpmyadmin; Μπορεί να συνδεθεί η Python;
    ο Apache
    η MySQL
    και τα δύο
    κανένα

    Διαλέγεις για το phpMyAdmin ανάμεσα σε: «ανοίγει και δουλεύει», «ανοίγει αλλά γράφει σφάλμα σύνδεσης», «δεν ανοίγει καθόλου».

    Όταν τελειώσεις, ξεκίνα ξανά και τα δύο.

  `id` INT NOT NULL AUTO_INCREMENT,
  `nickname` VARCHAR(20) NOT NULL,
  `score` INT NOT NULL,
  PRIMARY KEY (`id`)

    Αυτοέλεγχος¶

    • □ Μπορώ να εξηγήσω τη διαφορά ανάμεσα σε βάση, πίνακα, εγγραφή και πεδίο.
    • □ Ξέρω τι πρέπει να τρέχει στο XAMPP για να δουλέψει το phpMyAdmin και τι για να δουλέψει η Python.
    • □ Μπορώ να διαλέξω τύπο δεδομένων για μια στήλη και να εξηγήσω γιατί.
    • □ Ξέρω τι είναι το πρωτεύον κλειδί και γιατί το id δεν το γράφω εγώ.
    • □ Έφτιαξα τη βάση με δέκα παιχνίδια και έγραψα μόνος μου μια SELECT.
    • □ Σταμάτησα τον Apache και τη MySQL πριν φύγω.
