    Φύλλο εργασίας — Μάθημα 9: Ημερομηνίες και ώρες¶

    Πώς δουλεύουμε

    Η θεωρία είναι στη σελίδα Μάθημα 9. Εδώ είναι οι ασκήσεις. Στις ασκήσεις πρόβλεψης γράψε πρώτα την απάντησή σου και μετά τρέξε την εντολή ή το πρόγραμμα. Μια λάθος πρόβλεψη είναι χρήσιμη: δείχνει τι δεν έχει ακόμη γίνει σαφές. Σήμερα πρόσεχε τη μορφή της ημερομηνίας: στη βάση ΕΕΕΕ-ΜΜ-ΗΗ, στην οθόνη ΗΗ/ΜΜ/ΕΕΕΕ.

    Κύκλος Εργασία Αποτέλεσμα
    1 DATE, NOW(), DATE_FORMAT, DATEDIFF, στήλη added_on Ερωτήματα με ημερομηνίες στον games
    2 date, timedelta, strftime, strptime, ask_date Εφαρμογή με ημερομηνίες

    Οι δύο κύκλοι είναι οι δύο διδακτικές ώρες του μαθήματος.

    Κύκλος 1 — Ημερομηνίες στη SQL (45′)¶

    Θεωρία (10′)¶

    Παρακολούθησε την επίδειξη και διάβασε τις ενότητες 1.1–1.5 του μαθήματος.

    Α. Πρόβλεψη (4′)¶

    Πρόβλεψε το αποτέλεσμα κάθε εντολής. Μην τις τρέξεις ακόμη. Η DATEDIFF και η σύγκριση δίνουν αριθμό, η + INTERVAL δίνει ημερομηνία.

    # Εντολή Πρόβλεψη
    1 SELECT DATEDIFF('2026-10-01', '2026-09-15');
    2 SELECT '2026-09-15' + INTERVAL 20 DAY;
    3 SELECT DATE_FORMAT('2026-03-07', '%d/%m/%Y');
    4 SELECT MONTH('2026-12-25');
    5 SELECT '2026-09-05' < '2026-10-01';
    6 SELECT DATEDIFF('2026-09-15', '2026-10-01');

    Β. Βρες το σφάλμα (4′)¶

    1 SELECT * FROM games WHERE added_on = '15/09/2026';
    2 INSERT … added_on = '2026-02-30' (πριν υπάρξει CHECK)
    3 SELECT DATEDIFF('2026-09-15', '2026-12-25'); (θέλω πόσες ημέρες μένουν μέχρι τα Χριστούγεννα)
    4 WHERE added_on BETWEEN '2026-09-30' AND '2026-09-01'

    Α. Πρόβλεψη (4′)¶

    Δίνεται το παρακάτω κομμάτι προγράμματος (μην το τρέξεις). Τι θα τυπώσει, με τη σειρά;

    from datetime import date, timedelta

a = date(2026, 9, 15)
b = date(2026, 10, 1)
print(b - a)
print((b - a).days)
print(a + timedelta(days=20))
print(a.strftime("%d/%m/%Y"))
print(a < b)

    Αυτοέλεγχος¶

    • □ Ξέρω ότι η ημερομηνία γράφεται 'ΕΕΕΕ-ΜΜ-ΗΗ' στη SQL και ξέρω τι δείχνουν τα DATE, TIME, DATETIME.
    • □ Μπορώ να υπολογίσω διαφορά ημερών (DATEDIFF) και να προσθέσω χρόνο (INTERVAL).
    • □ Ξέρω τι κάνει η βάση με μια άκυρη ημερομηνία και πώς προστατεύομαι.
    • □ Μπορώ να φτιάξω ημερομηνία στην Python (date), να κάνω πράξεις (timedelta) και να την μορφοποιήσω (strftime).
    • □ Μπορώ να μετατρέψω κείμενο σε ημερομηνία (strptime) και να πιάσω το ValueError.
    • □ Ξέρω ότι ένα αντικείμενο date στέλνεται απευθείας ως παράμετρος στη MySQL.
