    Βάσεις δεδομένων με Python και MySQL¶

    Python & MySQL (XAMPP) — ΕΠΑΛ.

    Εργαστήριο 20 μαθημάτων, 2 διδακτικές ώρες το καθένα (2 κύκλοι των 45′ περίπου).

    Πώς δουλεύουμε¶

    Κάθε μάθημα προσθέτει ένα κομμάτι σε μια βάση δεδομένων που τη φτιάχνεις εσύ: μια βιβλιοθήκη βιντεοπαιχνιδιών, από τον πρώτο της πίνακα μέχρι μια ολοκληρωμένη εφαρμογή. Τα δύο πρώτα μαθήματα δουλεύουν στο phpMyAdmin και διδάσκουν τη γλώσσα των βάσεων, την SQL. Από το τρίτο η Python συνδέεται με τη βάση και γράφεις προγράμματα που διαβάζουν, προσθέτουν, αλλάζουν και σβήνουν δεδομένα. Στο τέλος σχεδιάζεις και παρουσιάζεις μια δική σου εφαρμογή.

    Δεν χρειάζεται να ξέρεις SQL. Χρειάζεσαι πολύ βασική Python: μεταβλητές, input και print, if και while. Κάθε έννοια εξηγείται όταν η εφαρμογή τη χρειάζεται και ακολουθούν ασκήσεις. Στην αρχή συμπληρώνεις κενά σε έτοιμο κώδικα. Όσο προχωράς, γράφεις όλο και περισσότερο μόνος σου.

    Σε κάθε άσκηση ακολουθείς τον ίδιο κύκλο:

    Ο κύκλος εργασίας

    πρόβλεψη → εκτέλεση → σύγκριση → εξήγηση

    Μια εντολή που τρέχει αλλά δεν μπορείς να την εξηγήσεις δεν θεωρείται ολοκληρωμένη εργασία.

    Δομή κάθε μαθήματος¶

    Σελίδα Τι περιέχει
    Μάθημα Η θεωρία: κάθε έννοια με παραδείγματα, βήμα-βήμα εκτέλεση και συνηθισμένα λάθη
    Φύλλο εργασίας Οι ασκήσεις κάθε κύκλου των 45′ περίπου: πρόβλεψη, ιχνηλάτηση, εντοπισμός σφαλμάτων, συμπλήρωση κενών, «γράψε εσύ»
    Αρχεία εργαστηρίου Οι σκελετοί κώδικα και τα αρχεία δεδομένων (.sql, .py) κάθε σταδίου

    Στην ενότητα «Αρχεία εργαστηρίου» κάθε μαθήματος πάτησε τον σύνδεσμο του αρχείου που χρειάζεσαι. Αν ανοίξει ως κείμενο στον φυλλομετρητή, αποθήκευσέ το ή αντίγραψέ το σε νέο αρχείο στον επεξεργαστή. Κράτησε το ακριβές όνομα και την κατάληξη (.sql ή .py, όχι .sql.txt). Φτιάξε δικό σου φάκελο ανά μάθημα.

    Τι χρειάζεσαι¶

    Τα βήματα εγκατάστασης και μια λίστα ελέγχου υπάρχουν στη σελίδα Εγκατάσταση και ρύθμιση.

    • XAMPP, με τον Apache και τη MySQL (στην πραγματικότητα MariaDB) και το phpMyAdmin. Χρειάζεται από το Μάθημα 1.
    • Python — ο τοπικός έλεγχος έγινε με 3.13. Έλεγξε με python --version (ή py --version, python3 --version). Χρειάζεται από το Μάθημα 3.
    • Έναν επεξεργαστή κώδικα, π.χ. VS Code.
    • Τον οδηγό σύνδεσης mysql-connector-python, από το Μάθημα 3 και μετά:
    python -m pip install mysql-connector-python

    Μαθήματα¶

    Το υλικό προστίθεται σταδιακά

    Οι σύνδεσμοι υπάρχουν μόνο για τα μαθήματα που έχουν ολοκληρωθεί. Η θεματολογία των υπόλοιπων είναι προσχέδιο και μπορεί να αλλάξει.

    Μέρος Α — Πρώτα βήματα: βάση δεδομένων και SQL

    # Μάθημα Τι μαθαίνεις
    1 Η πρώτη μου βάση δεδομένων βάση, πίνακας, εγγραφή, πεδίο, πελάτης–εξυπηρετητής, XAMPP, phpMyAdmin, τύποι δεδομένων, πρωτεύον κλειδί
    2 Η γλώσσα SQL: CREATE, INSERT, SELECT η καρτέλα SQL, κανόνες γραφής, CREATE TABLE, DROP TABLE, INSERT, SELECT με στήλες, AS, DISTINCT, υπολογισμούς και συναρτήσεις, ανάγνωση σφαλμάτων

    Μέρος Β — Python και MySQL

    # Μάθημα Τι μαθαίνεις
    3 Η Python συνδέεται με τη βάση mysql.connector, σύνδεση και σφάλματα σύνδεσης, cursor, execute, fetchall, λίστα από πλειάδες, for και αποδόμηση, μορφοποίηση σε στήλες, Decimal
    4 Φιλτράρω και ταξινομώ WHERE, AND/OR/NOT, BETWEEN, IN, ORDER BY, LIMIT, LIKE, η πρώτη σου συνάρτηση στην Python
    5 Προσθέτω δεδομένα από την Python INSERT και commit, παράμετροι %s, lastrowid, δεδομένα από το input(), γιατί η f-string στη SQL είναι επικίνδυνη (SQL injection), executemany
    6 Αλλάζω και σβήνω UPDATE και DELETE, ο ρόλος του WHERE, rows affected και rowcount, commit και rollback, επιβεβαίωση από τον χρήστη
    7 Εφαρμογή με μενού συναρτήσεις με παραμέτρους και return, τοπικές μεταβλητές, μενού με while True και break, πλήρης εφαρμογή διαχείρισης δεδομένων
    8 Σφάλματα και έλεγχος εισόδου try/except, έλεγχος τιμών, UNIQUE, NOT NULL, DEFAULT, NULL, CHECK, σφάλματα της βάσης στην Python
    9 Ημερομηνίες και ώρες DATE, DATETIME, NOW(), DATE_FORMAT, DATEDIFF, INTERVAL, το module datetime (date, timedelta, strftime, strptime), η ask_date
    10 Συγκεντρωτικά αποτελέσματα COUNT, SUM, AVG, MIN, MAX, GROUP BY, HAVING, συγκεντρωτικά αποτελέσματα και αναφορές στην Python

    Μέρος Γ — Πολλοί πίνακες και ολοκληρωμένες εφαρμογές

    # Μάθημα Τι μαθαίνεις
    11 Πολλοί πίνακες: το ξένο κλειδί επανάληψη δεδομένων, πρωτεύον και ξένο κλειδί, σχέση ένα-προς-πολλά, FOREIGN KEY, αναφορική ακεραιότητα (#1452, #1451), σχεδιασμός πινάκων
    12 JOIN: ερωτήματα σε πολλούς πίνακες INNER JOIN, LEFT JOIN, ψευδώνυμα πινάκων, ON, γραμμές χωρίς ταίρι (IS NULL), UPDATE με JOIN
    13 JOIN από την Python ερωτήματα με JOIN σε πρόγραμμα, λεξικά (dictionary=True), LEFT JOIN και None, DROP COLUMN, εφαρμογή με ξένο κλειδί (#1451, #1452)
    14 Σχέση πολλά-προς-πολλά πίνακας σύνδεσης, JOIN τριών πινάκων
    15 Οργάνωση του κώδικα δικό σου module για τη βάση, with, ρυθμίσεις σύνδεσης
    16 Αναφορές και εξαγωγή GROUP BY με JOIN, εξαγωγή σε αρχείο CSV
    17 Ασφάλεια χρήστες και δικαιώματα, SQL injection
    18 Αντίγραφα ασφαλείας και συναλλαγές εξαγωγή και εισαγωγή βάσης, mariadb-dump, COMMIT/ROLLBACK

    Μέρος Δ — Project

    Στα Μαθήματα 19–20 σχεδιάζεις, φτιάχνεις και παρουσιάζεις μια δική σου εφαρμογή με βάση δεδομένων, μαζί με έναν συμμαθητή.

    # Μάθημα Τι κάνεις
    19 Project (1/2): από την ιδέα στη βάση διαλέγεις θέμα, σχεδιάζεις πίνακες και σχέσεις και φτιάχνεις τη βάση
    20 Project (2/2): από το πρωτότυπο στην εφαρμογή γράφεις την εφαρμογή σε Python, ελέγχεις τη λειτουργία της και την παρουσιάζεις

    Πώς χρησιμοποιείς τους σκελετούς¶

    Τα αρχεία starter είναι ασκήσεις. Τα TODO και τα ____ δείχνουν σημεία που πρέπει να συμπληρώσεις· ένας σκελετός δεν τρέχει μέχρι να συμπληρωθούν τα κενά. Ο εκπαιδευτικός δείχνει πρώτα το επιδιωκόμενο αποτέλεσμα. Δούλεψε σε αντίγραφο, συμπλήρωσε ένα σημείο κάθε φορά και τρέχε το πρόγραμμα όσο πιο συχνά γίνεται. Σε μια εντολή που ξέρεις ότι δούλευε, αλλάζεις μία γραμμή τη φορά.
