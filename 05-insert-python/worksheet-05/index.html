    Φύλλο εργασίας — Μάθημα 5: Προσθέτω δεδομένα από την Python¶

    Πώς δουλεύουμε

    Η θεωρία είναι στη σελίδα Μάθημα 5. Εδώ είναι οι ασκήσεις. Στις ασκήσεις πρόβλεψης γράψε πρώτα την απάντησή σου και μετά τρέξε τον κώδικα. Μια λάθος πρόβλεψη είναι χρήσιμη: δείχνει τι δεν έχει ακόμη γίνει σαφές. Σήμερα, μετά από κάθε πρόγραμμα, έλεγχε και το phpMyAdmin (καρτέλα Browse του games).

    Κύκλος Εργασία Αποτέλεσμα
    1 INSERT, commit, %s, lastrowid, input Προγράμματα που αποθηκεύουν παιχνίδια
    2 Έγχυση SQL, παράμετροι στη SELECT, executemany, βρόχος με είσοδο Προσθήκη παιχνιδιών σε βρόχο

    Οι δύο κύκλοι είναι οι δύο διδακτικές ώρες του μαθήματος.

    Γ. Σωστό ή λάθος; (3′)¶

    Πρόταση Γιατί;
    1 Το commit() είναι μέθοδος του κέρσορα (cursor.commit()). Σ / Λ
    2 Όταν η τιμή είναι κείμενο, πρέπει να γράψω '%s' με εισαγωγικά. Σ / Λ
    3 Η executemany με λίστα από πλειάδες χρειάζεται ένα μόνο commit για όλες τις εγγραφές. Σ / Λ
    4 Η f-string μέσα σε SQL είναι ασφαλής όταν ο χρήστης δεν ξέρει SQL. Σ / Λ
    5 Μια SELECT με παράμετρο χρειάζεται commit. Σ / Λ

    Αυτοέλεγχος¶

    • □ Μπορώ να γράψω ένα INSERT από την Python με παραμέτρους και commit.
    • □ Ξέρω τι γίνεται αν ξεχάσω το commit και γιατί δεν υπάρχει σφάλμα.
    • □ Μπορώ να εξηγήσω την έγχυση SQL με ένα παράδειγμα.
    • □ Ξέρω ότι ό,τι έρχεται απ' έξω μπαίνει στη SQL μόνο ως παράμετρος.
    • □ Μπορώ να χρησιμοποιήσω παραμέτρους και στη SELECT, και να στείλω πολλές εγγραφές με executemany.
    • □ Ξέρω ότι το πρόγραμμά μου πρέπει να ελέγχει τι πληκτρολογεί ο χρήστης (Μάθημα 8).
