    Φύλλο εργασίας — Μάθημα 8: Σφάλματα και έλεγχος εισόδου¶

    Πώς δουλεύουμε

    Η θεωρία είναι στη σελίδα Μάθημα 8. Εδώ είναι οι ασκήσεις. Στις ασκήσεις πρόβλεψης γράψε πρώτα την απάντησή σου και μετά τρέξε τον κώδικα ή την εντολή. Μια λάθος πρόβλεψη είναι χρήσιμη: δείχνει τι δεν έχει ακόμη γίνει σαφές. Σήμερα κάθε φορά που κάτι αποτυγχάνει, ρώτα: ποιος το πιάνει, το πρόγραμμα ή η βάση;

    Κύκλος Εργασία Αποτέλεσμα
    1 try/except, συναρτήσεις που ρωτούν μέχρι σωστή τιμή Εφαρμογή που δεν σταματά με traceback
    2 UNIQUE, DEFAULT, NULL, CHECK, σφάλματα της βάσης στην Python Εφαρμογή με δύο γραμμές άμυνας

    Οι δύο κύκλοι είναι οι δύο διδακτικές ώρες του μαθήματος.

    Α. Πρόβλεψη (4′)¶

    1. Δίνεται το παρακάτω πρόγραμμα (μην το τρέξεις). Τι θα τυπώσει για κάθε είσοδο;

    number = int(text)

except ValueError:

    print("Α")

    print("Β")

except ValueError:
    print("Δ")
print("Ε")

    1 try: price = Decimal("abc") με except ValueError:

    Ε. Γράψε εσύ: περιορισμοί στις πλατφόρμες (5′)¶

    Στην καρτέλα SQL γράψε εντολές για τον πίνακα platforms:

    1. Το name να είναι μοναδικό. Δοκίμασε να προσθέσεις ξανά τη «Steam Deck». Ποιο σφάλμα βλέπεις;
    2. Η release_year να είναι από 1970 έως 2100. Δοκίμασε μια πλατφόρμα με χρονιά 3000. Ποιο σφάλμα βλέπεις;
    3. Πρόσθεσε μια σωστή πλατφόρμα, π.χ. «Atari 2600» (Atari, 1977).

    Υποδείξεις: ALTER TABLE … ADD UNIQUE (…) και ALTER TABLE … ADD CONSTRAINT … CHECK (… BETWEEN … AND …). Δώσε στον δεύτερο περιορισμό όνομα που δεν υπάρχει ήδη (π.χ. chk_platform_year).

    2. Τι είναι το NULL και πώς το ελέγχεις σε ένα WHERE; Ποιο είναι το αντίστοιχό του στην Python; ______________________________________________
    3. Ποιο σφάλμα πιάνει η except mysql.connector.IntegrityError και πώς βρίσκεις ποιο περιορισμό παραβιάστηκε; ______________________________________________

    Αυτοέλεγχος¶

    • □ Μπορώ να γράψω try/except με το σωστό όνομα σφάλματος και ξέρω γιατί δεν γράφω except: χωρίς όνομα.
    • □ Μπορώ να γράψω συνάρτηση που ρωτά μέχρι να πάρει έγκυρη τιμή (τύπος και εύρος).
    • □ Ξέρω τι κάνουν τα UNIQUE, NOT NULL, DEFAULT, NULL και CHECK, και πώς προστίθενται με ALTER TABLE.
    • □ Ξέρω ότι το NULL ελέγχεται με IS NULL και ότι στην Python είναι το None.
    • □ Μπορώ να πιάσω σφάλμα της βάσης με mysql.connector.IntegrityError και να διαβάσω το errno.
    • □ Μπορώ να εξηγήσω γιατί χρειάζονται και οι δύο γραμμές άμυνας.
