3. ΠΩΣ ΤΡΕΧΕΙ (βήμα προς βήμα)
------------------------------

3. Στην καρτέλα SQL, τρέξε ένα-ένα τα ερωτήματα του 03-account.sql (ως root).
4. Αντίγραψε το config_local.example.py ως config_local.py (ο κωδικός: ΣΥΜΠΛΗΡΩΣΕ).
5. Στο τερματικό, μέσα στον φάκελο: python app.py
