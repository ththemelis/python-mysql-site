README — ΠΙΤΣΑΡΙΑ ΦΟΥΡΝΟΣ (το ΠΑΡΑΔΕΙΓΜΑ του Μαθήματος 20)
=========================================================

Ομάδα: (παράδειγμα)


1. ΤΙ ΚΑΝΕΙ
-----------
Η εφαρμογή της πιτσαρίας «Φούρνος» για τον υπάλληλο που παίρνει τις παραγγελίες: εμφανίζει τον κατάλογο, κρατά τους πελάτες, καταχωρεί παραγγελίες με πολλά προϊόντα και ποσότητες, αλλάζει
την κατάστασή τους (new, ready, delivered) και δείχνει τα έσοδα ανά κατηγορία προϊόντων.


2. ΤΙ ΧΡΕΙΑΖΕΤΑΙ
----------------
- XAMPP, με ξεκινημένη τη MySQL (και τον Apache, για το phpMyAdmin)
- Python 3 και η βιβλιοθήκη mysql-connector-python (pip install mysql-connector-python)


3. ΠΩΣ ΤΡΕΧΕΙ (βήμα προς βήμα)
------------------------------
1. Ξεκίνα τη MySQL από το XAMPP Control Panel.
2. Στο phpMyAdmin, καρτέλα Import: τρέξε το 01-schema.sql και μετά το 02-data.sql (φτιάχνεται η βάση pizzeria).
3. Στην καρτέλα SQL, τρέξε ένα-ένα τα ερωτήματα του 03-account.sql (ως root): φτιάχνεται ο λογαριασμός pizzeria_app με δικαιώματα μόνο στη βάση pizzeria.
4. Αντίγραψε το config_local.example.py ως config_local.py (ο κωδικός είναι μέσα).
5. Στο τερματικό, μέσα στον φάκελο: python app.py


4. ΤΟ ΜΕΝΟΥ
-----------
  1. Εμφάνιση προϊόντων: ο κατάλογος, με κατηγορία και τιμή
  2. Νέος πελάτης: όνομα, τηλέφωνο (10 ψηφία, μοναδικό), διεύθυνση
  3. Νέα παραγγελία: διαλέγεις πελάτη και προϊόντα με ποσότητες (ΜΙΑ συναλλαγή: ή όλη η παραγγελία ή τίποτα)
  4. Αλλαγή κατάστασης παραγγελίας
  5. Παραγγελίες ενός πελάτη, με το σύνολο της καθεμιάς
  6. Έσοδα ανά κατηγορία
  0. Έξοδος


5. Η ΒΑΣΗ
---------
Βάση pizzeria με πέντε πίνακες: categories (κατηγορίες), products (προϊόντα, με ξένο κλειδί προς την κατηγορία), customers (πελάτες, μοναδικό τηλέφωνο), orders (παραγγελίες, με ξένο κλειδί προς
τον πελάτη, ώρα και κατάσταση με DEFAULT) και order_items (πίνακας σύνδεσης προϊόντων-παραγγελιών, με ποσότητα). Σχέσεις: κατηγορία 1:N προϊόντα, πελάτης 1:N παραγγελίες, παραγγελίες N:N προϊόντα.
Το διάγραμμα του Designer είναι στο αρχείο designer.png.


6. ΤΑ ΑΡΧΕΙΑ
------------
app.py            το μενού και ο χειρισμός των σφαλμάτων
queries.py        οι εντολές SQL (δεν τυπώνει και δεν ρωτά τον χρήστη)
ui.py             ό,τι ρωτά τον χρήστη και ό,τι τυπώνεται (με έλεγχο εισόδου)
db.py             η σύνδεση με τη βάση
config.py         οι ρυθμίσεις (βάση, λογαριασμός)
config_local.py   ο κωδικός (ΔΕΝ ανεβαίνει στο git και δεν τον δίνεις σε κανέναν)
01-schema.sql, 02-data.sql, 03-account.sql   η βάση, τα δεδομένα δοκιμής και ο λογαριασμός
check_queries.py  ελέγχει τις συναρτήσεις του queries.py χωρίς το μενού
test-plan.txt     ο πίνακας δοκιμών


7. ΔΟΚΙΜΕΣ
----------
Οι δοκιμές είναι στο test-plan.txt: 17 δοκιμές στο μενού (και οι 17 πέτυχαν) και ο έλεγχος check_queries.py (όλοι οι έλεγχοι OK).


8. ΟΡΙΑ ΚΑΙ ΕΠΕΚΤΑΣΕΙΣ
----------------------
- Δεν υπάρχει ακόμη ακύρωση ή διαγραφή παραγγελίας.
- Η τιμή που πληρώνει ο πελάτης είναι πάντα η τρέχουσα τιμή του καταλόγου (δεν αποθηκεύεται η τιμή τη στιγμή της παραγγελίας: ιδέα για επέκταση, μια στήλη unit_price στον order_items).
- Δεν υπάρχει σύνδεση χρηστών (κωδικός υπαλλήλου).
