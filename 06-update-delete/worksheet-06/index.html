    Φύλλο εργασίας — Μάθημα 6: Αλλάζω και σβήνω¶

    Πώς δουλεύουμε

    Η θεωρία είναι στη σελίδα Μάθημα 6. Εδώ είναι οι ασκήσεις. Στις ασκήσεις πρόβλεψης γράψε πρώτα την απάντησή σου και μετά τρέξε την εντολή ή το πρόγραμμα. Μια λάθος πρόβλεψη είναι χρήσιμη: δείχνει τι δεν έχει ακόμη γίνει σαφές. Σήμερα πρόβλεψε κάθε φορά πόσες γραμμές θα επηρεαστούν, και πριν από κάθε UPDATE ή DELETE κάνε SELECT με το ίδιο WHERE.

    Κύκλος Εργασία Αποτέλεσμα
    1 UPDATE, rowcount, αλλαγές από την Python Διορθωμένες τιμές και χρονιές
    2 DELETE, rollback, επιβεβαίωση Καθαρός πίνακας, σβησμένος με ασφάλεια

    Οι δύο κύκλοι είναι οι δύο διδακτικές ώρες του μαθήματος.

    Κύκλος 1 — Αλλάζω δεδομένα με UPDATE (45′)¶

    Θεωρία (10′)¶

    Παρακολούθησε την επίδειξη και διάβασε τις ενότητες 1.1–1.4 του μαθήματος.

    Α. Πρόβλεψη (4′)¶

    Πρόβλεψε πόσες γραμμές θα αλλάξει καθεμία από τις παρακάτω εντολές. Μην τρέξεις τις UPDATE. Για να ελέγξεις τις προβλέψεις 2 και 4, τρέξε SELECT COUNT(*) FROM games WHERE … με το ίδιο WHERE.

    # Εντολή Πρόβλεψη (γραμμές)
    1 UPDATE games SET price = 1 WHERE id = 5;
    2 UPDATE games SET price = 1 WHERE genre = 'Αγωνιστικό';
    3 UPDATE games SET price = 1 WHERE release_year = 2024;
    4 UPDATE games SET price = 1 WHERE price < 5;
    5 UPDATE games SET price = 1 WHERE id = 99;
    6 UPDATE games SET price = 1;

    Ποια εντολή είναι η πιο επικίνδυνη, και τι ξέχασε αυτός που την έγραψε; ______________________________________________

    Γ. Βρες το σφάλμα (4′)¶

    Πρόβλεψε τι θα γίνει με καθεμία από τις παρακάτω εντολές. Τρέξε τις 1, 2 και 4: δίνουν σφάλμα και δεν αλλάζουν τίποτα. Την 3 μην την τρέξεις. Αν τη δοκιμάσεις, ξαναδώσε στο id 3 την τιμή 2.99.

    # Εντολή Τι θα γίνει (πρόβλεψη) Διόρθωση
    1 UPDATE games SET price = 5.99, WHERE id = 1;
    2 UPDATE games WHERE id = 1 SET price = 5.99;
    3 UPDATE games SET price = 5.99 AND genre = 'Παζλ' WHERE id = 3;
    4 UPDATE games SET price = 5.99 WHERE title = Tiny Farm;

    Ποια από τις τέσσερις είναι η πιο ύπουλη και γιατί; ______________________________________________________________

    Ε. Γράψε εσύ: διορθώνω μια πλατφόρμα (7′)¶

    Σε νέο αρχείο 07-fix-platform.py γράψε πρόγραμμα που ρωτά το όνομα μιας πλατφόρμας και τη σωστή χρονιά της, και αλλάζει τη χρονιά στον πίνακα platforms. Η «Meta Quest» έχει λάθος χρονιά (2029): δώσε της την 2020. Το πρόγραμμα εμφανίζει:

    Η χρονιά της πλατφόρμας «Meta Quest» έγινε 2020.

    Αν δεν άλλαξε καμία γραμμή (rowcount ίσο με 0), να εμφανίζει ένα μήνυμα που το λέει.

    Υποδείξεις: τα πέντε βήματα της Python, δύο %s, πλειάδα με τη σειρά των %s, commit. Έλεγξε το αποτέλεσμα στο phpMyAdmin (πίνακας platforms, καρτέλα Browse).

    Κύκλος 2 — Σβήνω και ακυρώνω (45′)¶

    Θεωρία (10′)¶

    Ενότητες 2.1–2.4 του μαθήματος: η DELETE, το rowcount ως δίχτυ ασφαλείας, το rollback, η επιβεβαίωση από τον χρήστη.

    Α. Πρόβλεψη (4′)¶

    Πρόβλεψε πόσες γραμμές θα σβήσει καθεμία από τις παρακάτω εντολές, με τα δεδομένα της αρχής (18 γραμμές). Μην τις τρέξεις.

    # Εντολή Πρόβλεψη (γραμμές)
    1 DELETE FROM games WHERE id = 17;
    2 DELETE FROM games WHERE id IN (12, 13);
    3 DELETE FROM games WHERE title = 'Mini Golf';
    4 DELETE FROM games WHERE price < 1;
    5 DELETE FROM games WHERE id = 17 OR 1;
    6 DELETE FROM games;

    Ποιες δύο σβήνουν όλον τον πίνακα; Σε ποια από τις δύο το «ξέχασμα» δεν φαίνεται με την πρώτη ματιά; ______________________________________________

    2. Πριν το τρέξεις, γράψε την πρόβλεψή σου. (Για τον πρώτο αριθμό θυμήσου το αποτέλεσμα του ερωτήματος 5 στο Στάδιο 3.)

    Ε. Γράψε εσύ: έκπτωση με επιβεβαίωση (6′)¶

    Σε νέο αρχείο 08-discount.py γράψε πρόγραμμα που ρωτά ένα είδος και ένα ποσοστό έκπτωσης, εφαρμόζει την έκπτωση στα παιχνίδια του είδους, δείχνει πόσα παιχνίδια θα αλλάξουν, και ρωτά αν η αλλαγή θα γίνει μόνιμη:

    Η έκπτωση άλλαξε την τιμή σε 2 παιχνίδια.
Να γίνει μόνιμη η αλλαγή; (ναι/όχι): όχι
Ακυρώθηκε. Δεν άλλαξε τίποτα.

    Υποδείξεις: η UPDATE με SET price = ROUND(price * (100 - %s) / 100, 2) και WHERE genre = %s, με πλειάδα (percent, genre). Δεν κάνεις commit πριν ρωτήσεις. Μετά την απάντηση: commit αν γράψει «ναι», αλλιώς rollback. Δοκίμασε πρώτα με «όχι» (οι τιμές στο phpMyAdmin μένουν ίδιες) και μετά με «ναι».

    3. Γιατί, στο Στάδιο 4, το phpMyAdmin έδειχνε τις γραμμές ενώ το πρόγραμμα έβλεπε τον πίνακα άδειο; ______________________________________________

    Αυτοέλεγχος¶

    • □ Μπορώ να γράψω UPDATE με SET και WHERE, και να αλλάξω πολλές στήλες με κόμμα.
    • □ Ξέρω τι γίνεται αν ξεχάσω το WHERE σε UPDATE ή DELETE.
    • □ Κάνω SELECT με το ίδιο WHERE πριν αλλάξω ή σβήσω.
    • □ Μπορώ να στείλω UPDATE και DELETE από την Python με παραμέτρους, και να διαβάσω το rowcount.
    • □ Ξέρω τι κάνει το rollback() και γιατί το phpMyAdmin δεν βλέπει τις αλλαγές πριν το commit.
    • □ Ξέρω να ζητώ επιβεβαίωση πριν σβήσω, και ότι ό,τι δεν είναι ακριβώς «ναι» ακυρώνει.
