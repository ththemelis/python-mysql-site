    Φύλλο εργασίας — Μάθημα 3: Η Python συνδέεται με τη βάση¶

    Πώς δουλεύουμε

    Η θεωρία είναι στη σελίδα Μάθημα 3. Εδώ είναι οι ασκήσεις. Στις ασκήσεις πρόβλεψης γράψε πρώτα την απάντησή σου και μετά τρέξε τον κώδικα (στο sandbox.py ή στο αρχείο του σταδίου). Μια λάθος πρόβλεψη είναι χρήσιμη: δείχνει τι δεν έχει ακόμη γίνει σαφές.

    Κύκλος Εργασία Αποτέλεσμα
    1 connect, σφάλματα σύνδεσης, cursor, execute, fetchall Πρόγραμμα που διαβάζει τη βάση
    2 for και αποδόμηση, μορφοποίηση, Decimal, σύνολα Κατάλογος με σύνολα και ΦΠΑ

    Οι δύο κύκλοι είναι οι δύο διδακτικές ώρες του μαθήματος.

    Θεωρία (8′)¶

    Ενότητες 2.1–2.5 του μαθήματος: το αποτέλεσμα ως λίστα από πλειάδες, for και αποδόμηση, προσδιοριστές μορφής, Decimal, SQL ή Python, κλείσιμο.

    Α. Ιχνηλάτηση του βρόχου (5′)¶

    Εκτέλεσε στο χαρτί τον παρακάτω κώδικα και συμπλήρωσε τις τιμές στο τέλος κάθε γύρου.

    rows = [("A", 2), ("B", 5), ("C", 3)]
total = 0
for name, value in rows:
    total = total + value
    print(name, total)
    Γύρος name value total Τι εμφανίζεται
    1
    2
    3

    Μετά τον βρόχο: total = ______ και total / len(rows) = ______________

    Β. Σωστό ή λάθος; (3′)¶

    Πρόταση Γιατί;
    1 Η fetchall() επιστρέφει λίστα από πλειάδες. Σ / Λ
    2 Αν καλέσω δεύτερη φορά τη fetchall(), παίρνω ξανά τα ίδια δεδομένα. Σ / Λ
    3 Η τιμή μιας στήλης DECIMAL (π.χ. price) έρχεται στην Python ως float. Σ / Λ
    4 Αν το price είναι Decimal, το price * 1.24 δουλεύει κανονικά. Σ / Λ
    5 Στο for title, genre, price in rows: τα τρία ονόματα πρέπει να ταιριάζουν με τις τρεις στήλες του SELECT. Σ / Λ

    Αυτοέλεγχος¶

    • □ Μπορώ να γράψω από μνήμης τα πέντε βήματα και τις αντίστοιχες εντολές Python.
    • □ Ξέρω τι κάνω όταν δω 2003, 1049, 1045 και ModuleNotFoundError.
    • □ Μπορώ να διαβάσω τα δεδομένα μιας γραμμής με δείκτη (rows[0][1]) και με αποδόμηση.
    • □ Ξέρω γιατί το αποτέλεσμα του fetchall() διαβάζεται μία φορά.
    • □ Μπορώ να στοιχίσω δεδομένα σε στήλες με f-strings.
    • □ Ξέρω γιατί το price είναι Decimal και πώς το πολλαπλασιάζω.
