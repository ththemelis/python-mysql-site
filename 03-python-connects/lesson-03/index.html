    Μάθημα 3: Η Python συνδέεται με τη βάση¶

    Πρόγραμμα: ένα πρόγραμμα Python που συνδέεται στη game_library, διαβάζει τα παιχνίδια και τις πλατφόρμες και τυπώνει έναν κατάλογο με σύνολα
    Διάρκεια: 2 κύκλοι × περίπου 45′ εργασία (2 διδακτικές ώρες)

    Φύλλο εργασίας

    Αυτή η σελίδα εξηγεί τις έννοιες. Οι ασκήσεις και οι οδηγίες για κάθε κύκλο βρίσκονται στο Φύλλο εργασίας 3. Δούλεψε με τις δύο σελίδες ανοιχτές.

    Αρχεία εργαστηρίου¶

    Αρχείο Κύκλος
    01-connect.py 1
    02-first-query.py 1
    03-print-games.py 2
    04-final.py 2
    check-connection.py 1–2 (έλεγχος σύνδεσης όταν κάτι δεν δουλεύει)

    Η αποστολή¶

    Μέχρι τώρα έγραφες τη SQL στον φυλλομετρητή και την έβλεπες στο phpMyAdmin. Σήμερα το πρόγραμμά σου γίνεται πελάτης της MySQL, όπως περιέγραψε το Μάθημα 1: συνδέεται, στέλνει ένα ερώτημα SQL (από αυτά που έμαθες στο Μάθημα 2), παίρνει την απάντηση και την εμφανίζει όπως θέλεις εσύ. Στο τέλος θα έχεις ένα πρόγραμμα που τυπώνει τον κατάλογο των παιχνιδιών σε στήλες και υπολογίζει το σύνολο, τον μέσο όρο και το σύνολο με ΦΠΑ.

    Αυτό είναι το σημείο όπου η Python και οι βάσεις δεδομένων ενώνονται. Όλα τα επόμενα μαθήματα, μέχρι και το project στο τέλος, χτίζονται πάνω σε αυτή τη σύνδεση.

    Στο τέλος θα μπορείς¶

    • να εξηγείς τι είναι ο οδηγός σύνδεσης (connector) και να τον εισάγεις με import mysql.connector.
    • να συνδέεσαι στη βάση με connect() και να κλείνεις τη σύνδεση.
    • να διαβάζεις τα σφάλματα σύνδεσης (2003, 1049, 1045) και να ξέρεις τι να κάνεις.
    • να στέλνεις ένα ερώτημα με cursor.execute() και να παίρνεις τα αποτελέσματα με fetchall() και fetchone().
    • να εξηγείς ότι το αποτέλεσμα είναι λίστα από πλειάδες και να το διατρέχεις με for.
    • να εμφανίζεις δεδομένα σε στήλες με f-strings και προσδιοριστές μορφής (:<18, :>6.2f).
    • να ξεχωρίζεις τους τύπους που επιστρέφει η βάση (int, str, Decimal) και να δουλεύεις με Decimal.
    • να αποφασίζεις αν ένας υπολογισμός γίνεται στη SQL ή στην Python.

    Πριν αρχίσεις¶

    1. Ξεκίνα τη MySQL από το XAMPP Control Panel. Ο Apache δεν χρειάζεται για να δουλέψει η Python (μόνο το phpMyAdmin τον θέλει).
    2. Έλεγξε στο phpMyAdmin ότι η game_library έχει τον πίνακα games με δέκα εγγραφές και τον platforms με τέσσερις. Αν λείπει ή διαφέρει, ζήτα από τον εκπαιδευτικό το αρχείο που τη φέρνει στη σωστή κατάσταση.

    3. Έλεγξε την Python και τον οδηγό σύνδεσης στο τερματικό:

      python --version
python -c "import mysql.connector; print('ο οδηγός υπάρχει')"

      Αν η δεύτερη εντολή δώσει ModuleNotFoundError, εγκατάστησε τον οδηγό (σελίδα Εγκατάσταση και ρύθμιση, ενότητα 4):

      python -m pip install mysql-connector-python

    4. Φτιάξε έναν φάκελο 03-python-connects μέσα στον φάκελο των μαθημάτων. Κατέβασε εκεί τα πέντε αρχεία του πίνακα. Κράτησε ακριβώς τα ονόματα, με κατάληξη .py.

    5. Στο VS Code: File → Open Folder και διάλεξε τον φάκελο. Άνοιξε τερματικό: Terminal → New Terminal. Φτιάξε και ένα κενό αρχείο sandbox.py, το «τετράδιο πρόχειρου» για μικρές δοκιμές.

    Ο κύκλος εργασίας

    Πρόβλεψη → εκτέλεση → σύγκριση → εξήγηση. Πριν τρέξεις ένα πρόγραμμα, γράψε τι περιμένεις να δεις. Αν το αποτέλεσμα διαφέρει, βρήκες κάτι που αξίζει να καταλάβεις· δεν έκανες λάθος.

    Κύκλος 1 — Συνδέομαι και στέλνω το πρώτο ερώτημα¶

    Σε αυτόν τον κύκλο μαθαίνεις τα πέντε βήματα κάθε προγράμματος που μιλά με βάση δεδομένων, και τρέχεις τα δύο πρώτα στάδια.

    1.1 Πώς μιλά η Python με τη MySQL¶

    Στο Μάθημα 1 έμαθες ότι η MySQL είναι ένας εξυπηρετητής που περιμένει πελάτες στη θύρα 3306. Η Python δεν ξέρει από μόνη της να μιλά με αυτόν. Χρειάζεται ένα επιπλέον πακέτο, τον οδηγό σύνδεσης (connector), που ξέρει το «πρωτόκολλο» της MySQL: πώς στέλνεται ένα ερώτημα και πώς επιστρέφεται η απάντηση. Ο οδηγός που θα χρησιμοποιήσουμε λέγεται mysql-connector-python και στον κώδικα εισάγεται ως mysql.connector.

    πρόγραμμα Python ──► mysql.connector ──── ερώτημα SQL (θύρα 3306) ───► εξυπηρετητής MySQL
                                     ◄─── αποτέλεσμα ─────────────────

    Κάθε πρόγραμμα που δουλεύει με βάση δεδομένων κάνει πέντε βήματα. Τα έχεις ήδη κάνει στο phpMyAdmin, με κουμπιά:

    # Βήμα Στην Python Στο phpMyAdmin
    1 Σύνδεση mysql.connector.connect(...) ανοίγεις το phpMyAdmin και επιλέγεις βάση
    2 Κέρσορας connection.cursor() η καρτέλα SQL με το πεδίο κειμένου
    3 Ερώτημα cursor.execute("...") το κουμπί Go
    4 Αποτέλεσμα cursor.fetchall() ο πίνακας με τα αποτελέσματα
    5 Κλείσιμο cursor.close(), connection.close() κλείνεις το παράθυρο

    1.2 Ο οδηγός και το import¶

    Οι εντολές της Python δεν περιέχουν τα πάντα. Πολλές δυνατότητες βρίσκονται σε modules: έτοιμα αρχεία με συναρτήσεις που φορτώνεις με import, συνήθως στην αρχή του προγράμματος:

    import mysql.connector

    Από εδώ και πέρα γράφεις το όνομα του module μπροστά από ό,τι χρησιμοποιείς: mysql.connector.connect(...). Αν ο οδηγός δεν έχει εγκατασταθεί, η Python σταματά με:

    ModuleNotFoundError: No module named 'mysql'

    Η λύση είναι η εντολή python -m pip install mysql-connector-python (δες «Πριν αρχίσεις»). Πρόσεξε ότι το πακέτο λέγεται mysql-connector-python ενώ στον κώδικα γράφεις mysql.connector.

    Μην ονομάσεις δικό σου αρχείο mysql.py

    Αν έχεις στον φάκελο ένα αρχείο με όνομα mysql.py ή connector.py, η Python θα το φορτώσει αντί για τον οδηγό και το import mysql.connector θα αποτύχει με παράξενα μηνύματα. Δώσε στα αρχεία σου ονόματα που δεν ταιριάζουν με module (όπως τα 01-connect.py, 05-platforms-count.py).

    1.3 Η σύνδεση: connect()¶

    connection = mysql.connector.connect(
    host="localhost",
    user="root",
    password="",
    database="game_library",
)

    Η connect() παίρνει ονομαστές παραμέτρους (keyword arguments, όνομα=τιμή). Είναι τα ίδια στοιχεία που χρησιμοποιεί το phpMyAdmin:

    Παράμετρος Τι είναι Στο XAMPP
    host ο υπολογιστής όπου τρέχει η MySQL "localhost" (ο ίδιος υπολογιστής)
    user ο χρήστης της MySQL "root"
    password ο κωδικός του χρήστη "" (ο root του XAMPP δεν έχει κωδικό)
    database η βάση που θα χρησιμοποιήσεις "game_library"
    port η θύρα (προαιρετική) 3306 (η προεπιλογή· δεν χρειάζεται να τη γράψεις)

    Η connect() επιστρέφει ένα αντικείμενο σύνδεσης, που το κρατάς στη μεταβλητή connection. Δύο πράγματα που μπορείς να του ζητήσεις:

    • connection.is_connected() επιστρέφει True όσο η σύνδεση είναι ανοιχτή.
    • connection.close() κλείνει τη σύνδεση. Ένα πρόγραμμα πάντα κλείνει τη σύνδεση όταν τελειώσει.

    Μόνο για το XAMPP

    Ο root χωρίς κωδικό είναι βολικός για μάθηση, αλλά δεν θα έβαζες ποτέ τέτοια στοιχεία σε πραγματική εφαρμογή. Και ένας κωδικός γραμμένος μέσα σε ένα αρχείο φαίνεται σε όποιον το διαβάσει. Στο Μάθημα 17 θα μάθεις να φτιάχνεις χρήστη με περιορισμένα δικαιώματα και πώς κρατάς τα στοιχεία έξω από τον κώδικα.

    1.4 Όταν η σύνδεση δεν δουλεύει¶

    Η σύνδεση είναι το σημείο όπου αποτυγχάνουν τα περισσότερα προγράμματα την πρώτη μέρα. Η Python σταματά και εμφανίζει ένα traceback, όπως σε κάθε πρόγραμμα Python που αποτυγχάνει. Διάβασέ το με αυτή τη σειρά:

    1. Η τελευταία γραμμή λέει τι πήγε στραβά: τον τύπο του σφάλματος, τον αριθμό και μια εξήγηση.
    2. Η γραμμή File "…", line … που αναφέρει το δικό σου αρχείο (όχι αυτά του οδηγού) λέει πού.
    Traceback (most recent call last):
  File "01-connect.py", line 11, in <module>
    connection = mysql.connector.connect(
  ...
mysql.connector.errors.DatabaseError: 2003 (HY000): Can't connect to MySQL server on 'localhost:3306' (10061)

    Οι αριθμοί σφαλμάτων είναι οι ίδιοι που είδες στη SQL. Τα τέσσερα της σύνδεσης:

    Τελευταία γραμμή Αιτία Τι κάνεις
    2003 (HY000): Can't connect to MySQL server on 'localhost:3306' η MySQL δεν τρέχει (ή ακούει αλλού) πάτα Start στη MySQL στο Control Panel
    1049 (42000): Unknown database 'game_libary' δεν υπάρχει η βάση: συνήθως τυπογραφικό έλεγξε το όνομα στο phpMyAdmin
    1045 (28000): Access denied for user 'root'@'localhost' λάθος χρήστης ή κωδικός στο XAMPP: user="root", password=""
    2005 (HY000): Unknown MySQL server host 'lokalhost' λάθος όνομα εξυπηρετητή host="localhost"

    Ο γιατρός της σύνδεσης

    Αν κάτι δεν δουλεύει και δεν ξέρεις γιατί, τρέξε το check-connection.py που κατέβασες:

    python check-connection.py

    Δοκιμάζει τη σύνδεση και σου λέει με απλά λόγια τι φταίει και τι να κάνεις. Δεν χρειάζεται (ακόμη) να καταλάβεις τον κώδικά του. Το try/except που περιέχει θα το μάθεις στο Μάθημα 8.

    Άνοιξε το 01-connect.py. Συμπλήρωσε τα τέσσερα κενά (____) και τρέξε το από το τερματικό:

    Δοκίμασε μετά να σπάσεις τη σύνδεση σκόπιμα (στο φύλλο εργασίας θα σου πω πώς) και διάβασε το σφάλμα.

    1.5 Ο κέρσορας, το ερώτημα και το αποτέλεσμα¶

    Η σύνδεση μόνη της δεν στέλνει ερωτήματα. Για αυτό χρειάζεσαι τον κέρσορα (cursor): το «πεδίο κειμένου» του προγράμματός σου, όπως η καρτέλα SQL.

    cursor = connection.cursor()
cursor.execute("SELECT title, price FROM games")
rows = cursor.fetchall()
    • Η cursor.execute("...") στέλνει το ερώτημα στη MySQL. Μέσα στα εισαγωγικά γράφεις ακριβώς την εντολή SQL που θα έγραφες στο phpMyAdmin. Το ; στο τέλος είναι προαιρετικό.
    • Η cursor.fetchall() φέρνει όλες τις γραμμές της απάντησης και τις επιστρέφει ως λίστα.
    • Η SQL γράφεται μέσα σε συμβολοσειρά της Python. Αν η SQL περιέχει κείμενο σε μονά εισαγωγικά ('Sony'), η συμβολοσειρά της Python γράφεται με διπλά, και το αντίστροφο. Για ερώτημα σε πολλές γραμμές χρησιμοποίησε τριπλά εισαγωγικά:
    cursor.execute("""
    SELECT name, maker
    FROM platforms
""")

    Τι είναι η rows; Αν την εμφανίσεις με print(rows), βλέπεις:

    [('Star Dodger', Decimal('4.99')), ('Pixel Racer', Decimal('9.99')), ('Puzzle Garden', Decimal('2.99')), ...]

    (Η έξοδος είναι μεγαλύτερη· εδώ την έκοψα.) Είναι μια λίστα με πλειάδες, μία πλειάδα για κάθε γραμμή του αποτελέσματος.

    Θυμήσου: λίστες και πλειάδες

    • Η λίστα γράφεται με [ ] και κρατά πολλά στοιχεία με σειρά. Το πρώτο έχει δείκτη 0: rows[0]. Η len(rows) δίνει το πλήθος των στοιχείων.
    • Η πλειάδα (tuple) γράφεται με ( ) και μοιάζει με λίστα, αλλά δεν αλλάζει. Κάθε γραμμή του αποτελέσματος είναι μια πλειάδα με τις τιμές των στηλών, με τη σειρά που τις έγραψες στο SELECT: ('Star Dodger', Decimal('4.99')).
    • Έτσι το rows[0] είναι η πρώτη γραμμή, το rows[0][0] ο τίτλος της και το rows[0][1] η τιμή της.

    Το traceback είναι μακρύ, γιατί περνά μέσα από τον κώδικα του οδηγού. Η τελευταία γραμμή σού λέει τι έγινε. Ψάξε προς τα πάνω τη γραμμή File "…02-first-query.py", line …: εκεί είναι η εντολή σου.

    Κύκλος 2 — Διαβάζω και εμφανίζω τα δεδομένα¶

    Η rows έχει τα δεδομένα, αλλά ο χρήστης δεν θέλει να δει λίστες με πλειάδες. Σε αυτόν τον κύκλο μαθαίνεις να διατρέχεις τα αποτελέσματα, να τα στοιχίζεις σε στήλες και να υπολογίζεις με αυτά.

    2.1 Το αποτέλεσμα είναι λίστα από πλειάδες¶

    Η rows έχει τόσα στοιχεία όσες γραμμές έχει το αποτέλεσμα, και κάθε στοιχείο τόσες τιμές όσες στήλες έγραψες στο SELECT:

    Στο phpMyAdmin Στην Python
    title · price rows[0] → ('Star Dodger', Decimal('4.99'))
    Star Dodger · 4.99 → rows[0][0] → 'Star Dodger'
    Pixel Racer · 9.99 → rows[1] → ('Pixel Racer', Decimal('9.99'))

    Υπάρχουν δύο τρόποι να διαβάσεις το αποτέλεσμα:

    Μέθοδος Επιστρέφει
    cursor.fetchall() όλες τις γραμμές που απομένουν, ως λίστα
    cursor.fetchone() μία γραμμή (πλειάδα), και προχωρά στην επόμενη· όταν τελειώσουν, επιστρέφει None

    Το αποτέλεσμα διαβάζεται μία φορά

    Αν καλέσεις δεύτερη φορά τη fetchall() για το ίδιο ερώτημα, παίρνεις κενή λίστα []: οι γραμμές έχουν ήδη παραδοθεί. Αν τις θέλεις ξανά, κράτα τες σε μεταβλητή (rows) ή ξαναστείλε το ερώτημα.

    Φέρε όλο το αποτέλεσμα πριν συνεχίσεις: Unread result found

    Ο οδηγός θέλει να έχεις διαβάσει ολόκληρο το αποτέλεσμα ενός ερωτήματος πριν στείλεις το επόμενο ή κλείσεις τον κέρσορα. Αλλιώς σταματά με:

    mysql.connector.errors.InternalError: Unread result found

    Συμβαίνει όταν στέλνεις δεύτερη execute() χωρίς να έχεις καλέσει fetchall() για την πρώτη, ή όταν διαβάσεις μόνο μία γραμμή με fetchone() και μετά κλείσεις. Ο κανόνας: execute(), μετά fetchall(), και μόνο μετά το επόμενο ερώτημα ή το κλείσιμο.

    2.2 Ο βρόχος for και η αποδόμηση¶

    Για να περάσεις από όλες τις γραμμές, χρησιμοποιείς for:

    for row in rows:
    print(row[0], row[1])

    Το row[0] και το row[1] δεν λένε τι είναι. Η Python σού επιτρέπει να δώσεις ονόματα στα στοιχεία της πλειάδας μέσα στο ίδιο το for (αποδόμηση, unpacking):

    for title, price in rows:
    print(title, price)

    Σε κάθε γύρο η Python παίρνει την επόμενη γραμμή και βάζει το πρώτο της στοιχείο στο title και το δεύτερο στο price. Τα ονόματα πρέπει να είναι τόσα όσες οι στήλες του SELECT, αλλιώς:

    ValueError: not enough values to unpack (expected 2, got 1)

    (Εδώ το ερώτημα έφερνε μία στήλη και ο βρόχος περίμενε δύο. Το ανάποδο δίνει too many values to unpack.)

    Για να στοιχίσεις το αποτέλεσμα σε στήλες, χρησιμοποίησε προσδιοριστές μορφής μέσα στις f-strings, μετά την άνω-κάτω τελεία:

    Προσδιοριστής Τι κάνει Παράδειγμα Αποτέλεσμα
    {x:<18} αριστερά σε 18 θέσεις {'Tiny Farm':<18} Tiny Farm
    {x:>6} δεξιά σε 6 θέσεις {'Hi':>6} Hi
    {x:.2f} 2 δεκαδικά {4.9:.2f} 4.90
    {x:>6.2f} δεξιά σε 6 θέσεις, με 2 δεκαδικά {4.9:>6.2f} 4.90

    Έτσι κάθε γραμμή του καταλόγου έχει τα ίδια πλάτη και οι στήλες ευθυγραμμίζονται:

    for title, genre, price in rows:
    print(f"{title:<18} {genre:<14} {price:>6.2f} €")

    2.3 Οι τύποι που επιστρέφει η βάση¶

    Η βάση επιστρέφει κάθε τιμή με τον τύπο της Python που της ταιριάζει:

    Τύπος στη MySQL Τύπος στην Python Παράδειγμα
    INT int 2021
    VARCHAR, TEXT str 'Star Dodger'
    DECIMAL decimal.Decimal Decimal('4.99')
    NULL None None
    DATE (Μάθημα 9) datetime.date datetime.date(2024, 3, 15)

    Ο μόνος που δεν ξέρεις είναι ο Decimal. Η Python τον επιστρέφει για τις στήλες DECIMAL (όπως το price), για τον ίδιο λόγο που τον διαλέξαμε στη βάση: κρατά τα δεκαδικά ακριβώς. Δουλεύει σαν αριθμός, με μία παγίδα: δεν αναμειγνύεται με float:

    from decimal import Decimal

price = Decimal("4.99")
print(price * 2)             # 9.98            (με int: εντάξει)
print(price * 1.24)          # TypeError: unsupported operand type(s) for *: 'decimal.Decimal' and 'float'

    Δύο διορθώσεις. Η σωστή είναι να γράψεις τον συντελεστή ως Decimal (από κείμενο):

    VAT = Decimal("1.24")
print(price * VAT)           # 6.1876

    Η άλλη είναι να μετατρέψεις την τιμή σε float, αλλά τότε χάνεις την ακρίβεια που είχες στη βάση:

    print(float(price) * 1.24)   # 6.187600000000001

    Ξαναθυμήσου το 0.1 + 0.2 του Μαθήματος 1: αυτό το μικρό σφάλμα στο τέλος είναι ακριβώς ο λόγος που αποφύγαμε το FLOAT για χρήματα.

    2.4 Στη SQL ή στην Python;¶

    Το ΦΠΑ μπορείς να το υπολογίσεις και στις δύο πλευρές:

    # Στη SQL: η βάση κάνει τον υπολογισμό
cursor.execute("SELECT title, ROUND(price * 1.24, 2) FROM games")

# Στην Python: η βάση δίνει την τιμή και το πρόγραμμα την πολλαπλασιάζει
cursor.execute("SELECT title, price FROM games")

    Κανόνας που θα εφαρμόζουμε από εδώ και πέρα:

    • Στη SQL κάνεις ό,τι έχει να κάνει με επιλογή δεδομένων: ποιες γραμμές, ποια σειρά, πλήθος, αθροίσματα (Μαθήματα 4 και 10). Η βάση το κάνει γρήγορα και δεν στέλνει στο πρόγραμμα όσα δεν χρειάζεσαι.
    • Στην Python κάνεις ό,τι έχει να κάνει με παρουσίαση και λογική: μορφοποίηση, μηνύματα, αποφάσεις με if, επαναλήψεις.

    Στο Στάδιο 4 θα βρεις το άθροισμα των τιμών με βρόχο στην Python, για να εξασκηθείς. Στο Μάθημα 10 θα δεις ότι μία γραμμή SQL (SELECT SUM(price) FROM games) το κάνει με πολύ λιγότερο κόπο.

    2.5 Κλείσιμο¶

    Όταν τελειώσεις με το ερώτημα, κλείνεις πρώτα τον κέρσορα και μετά τη σύνδεση:

    cursor.close()
connection.close()

    Η MySQL επιτρέπει περιορισμένο αριθμό ταυτόχρονων συνδέσεων. Ένα πρόγραμμα που δεν τις κλείνει τις «κρατά» άσκοπα. Αν προσπαθήσεις να χρησιμοποιήσεις τον κέρσορα μετά το κλείσιμο, παίρνεις:

    mysql.connector.errors.ProgrammingError: 2055: Cursor is not connected

    Στο Στάδιο 4 κλείνουμε τη σύνδεση αμέσως μετά την ανάγνωση: τα δεδομένα βρίσκονται πια στις λίστες platforms και games και το υπόλοιπο πρόγραμμα δεν χρειάζεται τη βάση.

    Για να θυμάσαι¶

    • Η Python μιλά με τη MySQL μέσω ενός οδηγού (mysql-connector-python, import mysql.connector).
    • Τα πέντε βήματα: connect() → cursor() → execute() → fetchall() → close().
    • Η execute() παίρνει το ερώτημα SQL ως συμβολοσειρά, ακριβώς όπως θα το έγραφες στο phpMyAdmin.
    • Το αποτέλεσμα είναι λίστα από πλειάδες: μία πλειάδα ανά γραμμή, με τις τιμές με τη σειρά του SELECT.
    • Το αποτέλεσμα διαβάζεται μία φορά. Κράτα το σε μεταβλητή.
    • for title, price in rows: δίνει ονόματα στις στήλες· τα ονόματα πρέπει να είναι όσες οι στήλες.
    • Οι στήλες DECIMAL γίνονται Decimal. Δεν αναμειγνύονται με float.
    • Στο traceback διάβαζε την τελευταία γραμμή (τι) και τη γραμμή με το δικό σου αρχείο (πού).
    • Τα σφάλματα της SQL φτάνουν στην Python με τον ίδιο αριθμό.
    • Η SQL διαλέγει δεδομένα, η Python τα παρουσιάζει.
